# 怎么用「手」

装好之后，助手手上多了五件东西。下面按"我想干什么"来写。

---

## 一、先看边界

所有路径都必须落在 `roots` 里，默认是 `<宿主目录>`。
落在外面的路径会直接报错：

```
错误：读文件被拒绝：D:\x.txt 不在允许根目录内（<宿主目录>）
```

这不是故障，是护栏。要放宽就改 `data\config.json` 的 `roots`，
写 `["*"]` 等于不限制——不建议。

---

## 二、四件事

### 1. 看目录里有什么 — `hands_list`

```
hands_list { path: "<宿主目录>\\plugins" }
hands_list { path: "<宿主目录>", depth: 2 }
```

输出形如：

```
<宿主目录>\plugins
[D] hands
  [F] index.ts
  [F] plugin.yaml
```

`[D]` 是目录，`[F]` 是文件。单层最多列 200 项。不给 `path` 就列默认根目录。

### 2. 读文件 — `hands_read`

```
hands_read { path: "<宿主目录>\\package.json" }
hands_read { path: "...\\index.ts", offset: 120, limit: 80 }
```

`offset` 从 0 开始数行。默认一次 400 行，最多 4000。
超长会被截成"开头 + 中间省略 + 结尾"，不是静默丢内容。

**二进制文件不要用它**——它会按 UTF-8 解码，图、压缩包会变成乱码。

### 3. 写文件 — `hands_write`

```
hands_write { path: "<宿主目录>\\memory\\note.md", content: "# 标题\n内容" }
hands_write { path: "...\\note.md", content: "追加一行\n", append: true }
```

父目录不存在会自动建。默认覆盖，`append: true` 才是追加。

**覆盖是无声的**——没有备份、没有确认。写之前先 `hands_read` 看一眼原来是什么，
或者直接复制一份 `xxx.bak`。

### 4. 跑命令 — `hands_run`

```
hands_run { command: "Get-ChildItem -LiteralPath '<宿主目录>' | Select-Object -First 5 Name" }
```

给的是 **PowerShell 脚本**，不是 cmd 语法。几条规矩：

- `$` 不会被外层吃掉，写 `$value = 42` 就是 42
- 中文路径直接用，不会乱码
- 最后一条命令失败时退出码是 1（以前经常被骗成 0）
- 默认超时 60 秒，默认工作目录是根目录第一个
- 命中 `deny_patterns` 的命令直接拒绝，比如 `format `、`diskpart`、`shutdown`、`reg delete`
- 要跑 node、git 这些外部程序，照常写就行，不用包一层

**报"做完了"之前要看回执**：退出码 0 不等于文件写成了。

## 三、写了文件怎么证明写成了 — `verify_files`

这是最值钱的一件。跑命令的同时声明"我改了哪个文件、里面必须有什么、必须没有什么"：

```
hands_run {
  command: "node build.mjs > out.json",
  cwd: "<宿主目录>",
  verify_files: [
    {
      path: "out.json",
      contains: ["\"version\": \"1.0.0\""],
      absent: ["undefined"]
    }
  ]
}
```

跑完之后插件自己回读文件，逐条比对字面量，然后报三种结果：

| 状态 | 意思 |
|---|---|
| `已验证变化` | 断言全过，且文件内容跟执行前不一样 |
| `已满足且无变化` | 断言过了，但内容没变（重复写同一份，或命令没生效） |
| `验证失败` | 缺字面量 / 还残留不该有的字面量 / 文件不见了 / 读不到 |

注意 `已满足且无变化` —— **它不是说命令成功了**，是说文件最后的样子符合断言但跟之前一样。
如果你的意图是"必须改掉"，这一条要当成没改。

`verify_files` 最多 10 个文件，每个至少要一条 `contains` 或 `absent`，路径不能重复。

---

## 四、几个常见错误

| 报错 | 原因 |
|---|---|
| `不在允许根目录内` | 路径越界，或用了相对路径但 cwd 猜错了 |
| `命令被拒绝：命中禁止项「format 」` | 命令文本里含 `deny_patterns` 中的串，连 `Get-Date -format` 都会被拦（用 `[DateTime]::Now.ToString('...')` 绕开） |
| `启动 PowerShell 失败` | 系统里找不到 `powershell.exe`，或临时目录不可写 |
| `写临时脚本失败` | `%TEMP%` 没有写权限 |
| 退出码 1、stderr 里有中文 | 正常报错，中文路径和消息都完整可读 |

---

## 五、从日常版换到纯净版要注意什么

两台机器或多份安装各管各的，
两边的 `data\config.json` 是独立的。换目录跑，先改 `roots`，否则什么都碰不到。

插件本身不写日志，所有执行痕迹在宿主日志里；临时 `.ps1` 跑完即删，
中断时也会删，不会在 `%TEMP%` 里堆东西。
